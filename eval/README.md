# 집사서 자격 판정 평가셋 (2026-11-26 작성)

가상 신청자 15명이 공고 6건에 각각 지원할 수 있는지를 정답으로 적어 둔 평가셋입니다. 서비스가 낸 판정과 근거 인용을 이 정답과 비교해 성능을 숫자로 확인하는 데 씁니다.

> ⚠️ 정답은 Claude가 공고문 파싱 결과를 읽고 만든 초안입니다. 근거 문장이 원문에 글자 그대로 있는지는 스크립트로 전부 확인했지만, **판정 논리 자체는 사람이 아직 검토하지 않았습니다.** 수치를 외부에 제시하기 전에 최소한 "까다로운 사례"는 직접 확인하세요.

## 판정 값

- **가능**: 공고문에 적힌 자격 요건을 충족합니다. 당첨이나 자금 여력을 뜻하지 않습니다.
- **불가**: 공고문의 요건 중 하나 이상을 충족하지 못합니다.
- **확인필요**: 공고문만으로는 정할 수 없습니다. 공고문 안의 문구가 서로 다르게 읽히거나, 판정에 필요한 금액이 공고문에 없는 경우입니다. 이때는 단정하지 않고 확인이 필요하다고 답해야 정답입니다.

분포는 가능 33건, 불가 53건, 확인필요 4건입니다. 전부 "불가"라고만 답해도 59%가 맞으므로, 정확도는 이 값과 비교해서 읽어야 합니다. N6은 외국인만 빼고 모두 가능이라 변별력이 낮습니다.

각 공고는 따로 판정했습니다. 한 사람이 여러 공고에 동시에 신청할 수 있는지(중복 신청 제한)는 다루지 않습니다. 나이와 자격은 각 공고의 입주자모집공고일 기준입니다.

## 만든 방법

1. AutoRAG가 파싱한 공고문 Markdown 6건을 공고마다 하위 에이전트가 끝까지 읽고 자격 기준과 근거 문장을 뽑았습니다(근거 1,017개, 전부 원문 대조 통과).
2. 그 기준으로 신청자 15명을 설계하고 90건을 판정했습니다. 금액은 기준선에서 여유를 두었고, 경계 사례는 일부러 따로 넣었습니다.
3. 판정에 쓴 근거 223개가 파싱된 공고문의 해당 줄에 글자 그대로 있는지 검사했습니다.

근거의 `line`은 AutoRAG 2.15.0 파싱 결과(`workspace/.autorag/minsync/files/<corpus_file>.md`)의 줄 번호입니다. 파서 버전이 달라지면 줄 번호가 바뀔 수 있고, 검사 스크립트는 이 경우 경고만 냅니다. `quote`에는 표의 HTML 태그가 그대로 들어 있는 것이 있습니다.
